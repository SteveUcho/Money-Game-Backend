# Monorepo Backend
## Go(Gin) + ORY Kratos + PostgreSQL + Goose + SQLc
- REST API in go using gin framework
- Authentication using ORY Kratos
- Database using PostgreSQL
- Database migrations using Goose
- Database queries using SQLc

## Setup docker-compose

1. set values in .env file following template .env.template
2. run docker compose up

```bash
docker compose up
```
